# Dashboard landscape

`landscape.png` is original generated scenery, created with the built-in image-generation tool for Alpha 9.3. It is a decorative background, not an OSRS location screenshot or a source of account/game data. The supplied design_refs images informed the dashboard's hierarchy and atmosphere; their embedded controls and sample account values were not copied into the live UI.

Final generation prompt:

> Create a text-free background illustration for a medieval fantasy game companion desktop dashboard. Wide landscape 1536x1024. Nostalgic low-poly early-2000s MMORPG aesthetic, angular green trees, a small stone castle and timber village beside a winding river, distant blue mountains, warm late afternoon light. Rich muted forest greens, slate blue and earthy stone; restful composition with main scenic detail near left and right edges, center less busy for live interface controls. Environment only: no characters, no text, no letters, no logos, no interface, no borders, no buttons. Original scenery, not an exact replica of a specific game location.
